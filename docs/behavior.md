# 交互与持久化行为说明

本文档记录 Aion 在前端交互、后台异步保存、并发保护及视图状态上的行为约束。

## 自动保存与草稿一致性

- 任务与投递详情的输入先保留在本地草稿中，由后台按顺序自动保存；连续输入只保留最新的待保存版本。
- 保存期间界面会显示“正在保存”。此时若切换模块、切换项目/记录或关闭详情，会在保存成功后执行最后一次请求。
- 保存失败或输入无效时会保留草稿；保存尚未完成时，请等待后再退出应用或恢复备份。
- 投递阶段变更、时间线写入和详情保存按输入顺序执行，写入完成前会阻止退出应用和恢复备份；提交备注后可立即继续输入下一条。
- 页面、项目、投递列表与详情在后台加载，较早返回的加载结果不会覆盖新页面或新输入。

## 放弃修改与保存失败恢复

- 后台保存期间点击“放弃修改”后，可以继续编辑。
- 若前一笔保存失败，编辑器会恢复受影响的字段，并保留随后提交的修改和正在输入的文字（包括对子任务的改名以及投递备注中的换行）。
- 调整子任务顺序时，后续保存优先保留放弃后改变的相对顺序（包括新增子任务的位置），并尽量保留数据库里原有的顺序。

## 看板、记录与设置的后台写入

- 看板移动、排序、修改优先级、创建记录、回收站恢复和保存设置均在后台执行，等待数据库期间仍可继续输入或切换页面。
- 记录写入完成后可以再次提交，等待期间输入的新内容会保留。
- 连续保存同一项设置时，会保留最新的待保存值。请等待写入完成后再关闭窗口或恢复备份。
- 勾选全部子任务不会强制将父任务标为已完成。

## 求职投递视图与时间线规则

- 提供「全部投递 / 进行中 / 已获 Offer / 已结束」四个视角、顶部 Offer 转化率指标及无边框横向滚动列表，支持行内阶段/状态快速流转、公司/岗位 `⌘F` 页内搜索与多条件筛选分页、`http/https` 投递链接一键复制与系统浏览器打开，以及同名进行中投递非阻塞提醒。
- 投递条目在「今天」和「求职」视图均展示公司图标：填写 `http/https` 投递链接时，桌面宿主通过 `Host.LoadFavicon` 后台异步抓取网站图标（支持 PNG/JPEG/GIF/WebP/原生 ICO 解码，依次尝试根路径图标、HTML `<link>` / `<meta>` 及 SPA 内嵌 JSON 图标字段如飞书招聘 `browser_label_img_url`，内存有界 LRU 64 条 + 系统缓存目录持久化）；未填链接、加载中或抓取失败时平滑降级为公司首字图标。
- 投递详情弹窗支持「结束流程（含 Offer 结果阶段确认）/ 重新开启（支持填写可选重启备注并写入 `reopened` 时间线事件）」、追加时间线备注，以及只写历史不覆盖当前进度的阶段事件补录。
- 投递列表的「最近更新」按保存时间排序，包括补录历史阶段和编辑时间线；补录的节点在时间线中按所选的发生日期显示。
- 空状态提示：
  - 尚无投递且未启用筛选时，空页面会引导新增第一条投递。
  - 已有投递时，「进行中」「已获 Offer」「已结束」各自说明当前分类为空。
  - 筛选无结果时，可直接点击清除筛选。

## 自动静默检查更新与应用内更新弹窗

- 在正式可自更新的打包版本中，应用启动后延迟约 10 秒执行一次静默检查，随后按设置页配置的周期（默认开启，每天一次，可选每 6 小时 / 每 12 小时 / 每天）及系统休眠唤醒后补查；开发构建与不可写安装位置不执行后台检查。
- 后台静默检查不会自动下载或安装，也不会弹窗打断；网络异常静默退避重试，且不会覆盖已发现的可用版本。
- 发现新版本（或处于下载、安装、待重启状态）时，顶部栏右侧展示圆圈向上箭头更新图标按钮（带悬停提示）；无新版本或已跳过该版本时隐藏。
- 点击顶部栏更新图标、菜单栏「检查更新…」或设置页「检查更新」统一打开应用内更新弹窗，直接展示已获取的 Markdown 更新说明，并提供「跳过此版本」「稍后提醒」「下载并安装」「取消下载」「立即重启」等操作；「立即重启」经由窗口关闭前校验保护未保存草稿。
- 「自动检查更新」开关与频率偏好异步写入本地设置（不阻塞界面，备份恢复后会重新同步到宿主调度器）；上次检查时间与已跳过版本保存在本机独立状态文件，不持有 SQLite `Store` 锁，也不随备份恢复覆盖。

## 本地 MCP 接入与实时联动

- 可通过 `Aion mcp [-data-dir <路径>]` 启动标准 stdio MCP Server，供 Antigravity、Codex 等本地 AI 客户端直接读写项目、任务（含跨项目搜索 `search_tasks` 与受管附件导入 `attach_file_to_task`）、求职投递（含阶段流转、备注与历史补录）及回收站恢复；**不开放**彻底删除、清空回收站、备份恢复与系统设置写入。
- 同一套本地 IPC/降级路由同时驱动轻量 CLI（`Aion summary`、`Aion project`、`Aion task`、`Aion job`、`Aion trash`，均支持 `-data-dir` 与 `-json`），仓库中的 [aion-workbench Skill](../skills/aion-workbench/SKILL.md) 约定了每日聚焦复盘、JD 建单与面试时间线维护流程。
- 所有 `update_*` 工具采用局部更新语义：未传入的字段保留原值，避免 AI 修改局部信息时误清空描述、标签、子任务或备注。
- `aion mcp` 空闲时不持有 `.aion.lock` 或 SQLite 连接，可随时与桌面端并存或同时挂载多个客户端：桌面端运行时经由本地 IPC Socket（`aion.sock`）复用主进程并在写成功后实时刷新界面；桌面端未运行时按单次调用短打开本地数据库并立即释放锁。
- 外部写入触发实时刷新时严格遵守草稿保护：若当前任务或投递详情弹窗中存在未保存草稿或正在后台保存，外部变更不会覆盖正在编辑的表单内容，也不静默关闭未保存草稿；无脏草稿时详情视图随外部变更静默同步。
- 设置页（`⌘,`）中的「本地接入」区展示本机实时联动状态（与「今天」页同步状态共用实时 `MCPCapability()`），并提供一键复制 **Antigravity（JSON）**、**Codex（`codex mcp add`）** 与 **CLI 软链安装（`~/.local/bin/aion`）** 命令（自动包含当前可执行路径及自定义 `-data-dir`）。

## 顶部导航、聚焦总览、看板筛选与全局快捷键

- 顶部栏采用居中悬浮导航胶囊（`今天` / `项目` / `求职` / `设置`）与右侧工具集群（更新提示、搜索 `⌘K`、回收站、GitHub Issues 问题反馈、深浅外观与统一 `+ 新建` 下拉），左上角仅保留 macOS 交通灯留白。
- 设置页的「工作区」支持按当前生活阶段隐藏或重新显示内置模块（例如求职季结束时暂时隐藏「求职」）；隐藏仅收起顶栏胶囊、命令面板与聚焦总览中的入口，不会删除 SQLite 或备份中的任何数据，且至少保留一个可见模块。
- 「今天」聚焦总览（`⌘1`）自动适配当前可见模块：左侧提供「待推进（逾期 / 7 天内截止 / 进行中 / 高或紧急优先级）/ 进行中 / 全部未完成 / 已完成」筛选与活跃项目完成进度，支持行内快捷开始/完成；右侧展示进行中求职（含网站/首字图标与行内推进阶段）及实时本地 MCP 状态。
- 看板顶部拆分为「项目切换行（含所有项目入口、悬停零位移原地编辑槽位、已归档入口与新建项目按钮）」与「筛选行（关键词 `⌘F`、优先级、截止日期快捷筛选、多标签交集筛选与 `+ 新建任务`）」；任务详情右侧抽屉底部展示创建、更新与完成时间（`CompletedAt`）。
- 全局快捷键：`⌘K` 打开/关闭全局命令面板（跨可见模块搜索活跃与已归档项目/任务、投递记录并执行快捷操作，含「反馈与建议」；点击已结束投递自动路由到「已结束」视图），`⌘1` 聚焦总览，`⌘2` 项目工作区，`⌘3` 求职工作区，`⌘,` 打开设置，`⌘F` 聚焦当前看板或求职列表的页内搜索框；其它弹窗打开期间不会叠加触发全局导航或命令面板。
- 隐藏偏好（`app.hidden_modules`）异步写入本地设置，并在备份恢复后自动重新同步当前模块与导航状态。
